# Apana Insurance website preview

Design preview of the redesigned apanainsurance.com. One self-contained page (`index.html`) with hash-based navigation between Home, the six guides, Seminars, About, FAQ, Articles and Contact.

This is a design reference for the production build. Forms are not connected, and items in [brackets] are waiting on details from Apana Insurance. The page carries a `noindex` tag.

## Redesign (v2)

`v2/index.html` is a second design pass of the same site: same pages and wording, new visual design. The approved version at the repository root is unchanged. Once on `main` it is served at `/v2/`.
